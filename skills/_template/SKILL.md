# Skill 名称

## 目标

说明这个 Skill 要解决的业务问题。

## 可用数据

只使用 skill.yaml 中声明的 MCP Tool，并说明外部数据的适用范围。

## 执行原则

说明如何组合 Tool，以及没有结果时如何表达。

## 证据原则

外部 MCP 数据属于外部证据，不自动等同于内部年报 EvidenceUnit。

## 输出要求

输出可供上层 Agent 使用的辅助信息，不直接形成正式评级结论。

## 禁止事项

- 不得调用 manifest 未声明的 Tool。
- 不得把外部数据自动写入正式 Ontology。
- 无结果不得解释为事实不存在。
