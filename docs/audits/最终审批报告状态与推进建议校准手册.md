# 最终审批报告状态与推进建议校准手册

## 需求

最终审批报告不应把一般性的持续监测全部写成“有条件通过”。报告需清楚区分：材料已足以支持判断的“通过”，存在实质跟踪事项的“有条件通过”，有明确不利事实的“不通过”，以及无法形成判断的“信息不足”。

推进建议应与 AAA、AA、A、BBB、BB、B、CCC、CC、C 九级评级保持直观一致，不能出现 C 级仍显示“可推进”的情况。

## 统一判断规则

- **通过**：无明确不利事实，且原始披露已足以形成该方向的实质判断。缺少同行指标、单项非关键明细或仅需日常监测，不影响通过。
- **有条件通过**：存在与该方向直接相关的实质跟踪事项，例如未到期的特殊权利、转型成效尚待兑现、明确整改承诺、经营波动或融资安排。
- **不通过**：存在直接不利事实，且当前材料不能证明已解除或充分缓释。
- **信息不足**：缺少形成实质判断所必需的信息；不能用作虚构负面事实。

## 推进建议与等级

| 综合等级 | 推进建议 | 含义 |
| --- | --- | --- |
| AAA | 审慎推进 | 无不通过项，且没有非量化关键信息不足。 |
| AA | 审慎推进 | 无不通过项，但存在需专项核实的信息边界。 |
| A / BBB / BB / B | 有条件推进 | 存在 1-4 项弱约束不通过，应落实针对性条件并复核。 |
| CCC / CC | 不建议推进 | 存在较多弱约束不通过，或规范性与财务风险同时失败。 |
| C | 不建议推进 | 存在强约束不通过。 |

## 实现步骤

1. 在提示词中写明“通过”与“有条件通过”的边界，供以后模型调用沿用。
2. 将推进建议改为由 11 条方向状态确定，并强制与九级评级边界一致。
3. 审核现有 12 份报告：仅把“缺少非关键明细/同行指标、但原文事实已经充分”的条目改为通过；存在真实跟踪事项的条目保持有条件通过。
4. 同步更新改动条目的文字、总体判断和风险/核实清单，并运行现有校验测试。
