# 最终审批报告信息不足全量复核手册

## 目标

以当前 `robotics_2025_assumption_test` 批次 12 家企业的 `final_v5` 客户风险评级报告为唯一对象，重新核查每一条“信息不足”结论是否确实缺少原始 PDF 支持。

本次不沿用此前人工修正结论，不调用模型，不重新生成画像；仅使用原始 PDF、已入库原文切片、企业画像和当前方向报告复核，并直接修正有原文支持的最终结论。

## 审查范围

1. 逐家读取最终报告的全部 `insufficient_information` 方向；
2. `quantitative_assessment` 单列为方法边界：它是试验性样本排名检查，不属于“PDF 未提取企业信息”，不据此修改企业事实结论；
3. 其余方向逐项检查：
   - 是否存在直接支持结论的企业事实；
   - 该事实是否已入库但未进入方向报告；
   - 该事实是否能支持“通过”或“有条件通过”，而不仅是提供零散背景；
   - PDF 是否确实没有交易对手实名、制裁筛查、市场份额、订单或其他被指出的关键资料。

## 执行步骤

1. 从数据库导出 12 家企业的当前最终报告、信息不足方向和原结论；
2. 针对每个方向，在同一企业的 `evidence_units` 中检索相应主题词，并记录证据编号及其原 PDF 页码；
3. 直接读取命中页的原 PDF，确认不是目录、标题或行业泛化表述；
4. 按下列唯一结论处理：
   - `已披露且足以判断`：改为“通过”；
   - `已披露但仍有实质跟踪事项`：改为“有条件通过”；
   - `仅有行业泛化/零散背景`：保留“信息不足”；
   - `PDF 未披露关键资料`：保留“信息不足”。
5. 每次修改后重建最终报告的总体判断、风险清单、行动建议和推进建议，并运行 11 个方向、九级评级边界与证据引用校验。

## 固定边界

- 不将“未检索到”改写为负面事实；
- 不用行业市场份额替代企业自身市场地位；
- 不用客户匿名代称或出口管制风险提示替代实名 KYC、受益所有人和制裁筛查材料；
- 反洗钱与制裁方向只有存在直接违规触发事实才能不通过；没有筛查资料时仅保留为信息不足；
- 不因补充“通过/有条件通过”项改变已存在的明确不通过事实或九级评级边界。
