# 当前功能清理执行手册

## 需求

系统只保留当前界面中的四个工作区：材料管理、企业画像、行业背景、客户风险评级报告。

历史案例、相似企业比较、比较卡、核心风险判断旧服务，以及它们专用的旧提示词和命令行脚本，不再保留为隐藏功能或兼容入口。

## 实施步骤

1. 确认 `v5_app.py` 的主入口只调用四个工作区，并移除旧工作区函数、旧服务导入和旧页面状态处理。
2. 从 `src/ui/v5_services.py` 移除历史案例分析、比较卡、相似企业、详细比较和旧核心风险判断服务；保留当前授信审批所需的审批报告、排名和综合评级服务。
3. 删除只服务于上述旧功能的脚本、旧提示词和旧模块引用；不删除当前企业画像、行业背景和授信审批依赖的通用模块。
4. 搜索旧功能名称、旧提示词路径和隐藏入口，确认当前代码不再引用。
5. 运行编译检查和现行自动化测试，确认四个工作区的导入、画像分析、行业背景和审批报告功能未受影响。

## 验收标准

- `v5_app.py` 的主入口只有四个业务工作区和开发调试入口。
- 主流程代码不再读取 `prompts/legacy/`。
- 项目中不再保留历史案例、比较卡、相似企业和旧核心风险判断的隐藏服务入口。
- 当前主流程提示词仍从 `prompts/data/`、`prompts/logic/` 和 `prompts/action/` 读取。
- 自动化测试全部通过。

## 执行状态

- 已移除当前界面之外的历史案例、比较卡、相似企业和旧核心风险判断页面及服务。
- 已移除 `prompts/legacy/` 及其旧提示词。
- 已移除上述旧功能的专属命令行脚本和测试。
- 当前 `v5_app.py` 只保留四个业务工作区；审批后台模块仍保留，因为客户风险评级报告页面需要它们。
