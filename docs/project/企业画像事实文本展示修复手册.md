# 企业画像事实文本展示修复手册

## 需求

企业画像页面中的事实值、事实编号、主题分析信号和证据编号必须完整显示。动态内容不能被 Markdown 的下划线、反引号或其他符号误解析，也不能因为拼接到标题或表格单元格而丢失可读性。

## 实现步骤

1. 保留企业画像事实、证据和主题分析的数据结构不变。
2. 检查页面中所有动态文本的渲染位置，特别是事实值、分析信号和编号。
3. 动态事实内容使用纯文本组件展示；固定标签仍可使用 Markdown 加粗。
4. 长值仍保留完整原文，不增加截断、清洗或改写规则。
5. 用包含下划线编号和长技术名称的页面测试渲染，确认数据内容未被修改。

## 验收标准

- `p_005007`、`tech_ip_008010` 等编号按原样显示；
- “移动机器人多车型多路径调度系统”等长名称完整可读；
- 事实值、分析结论和证据引用没有被 Markdown 格式化误伤；
- 不改变数据库内容、事实数量和证据关联。
