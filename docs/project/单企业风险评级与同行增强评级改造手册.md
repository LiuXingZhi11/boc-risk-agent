# 单企业风险评级与同行增强评级改造手册

## 需求

客户风险评级报告应支持只依据一家企业画像和行业背景画像完成，不得因为没有同行样本或同行排名而无法生成。同行比较和排名作为可选增强信息；存在时用于补充相对位置，不存在时写明未进行同行比较，不将缺少比较自动判定为风险。

## 实现步骤

1. 将分方向报告的同行样本组改为可选输入；单企业模式下，分方向报告只使用企业画像、行业背景和风险评级指引。
2. 允许分方向上下文没有同行样本和可比指标，相关审批点记录为“未进行同行比较”或信息边界，不改变事实判断。
3. 将最终评级的必需输入改为目标企业完整的 11 个分方向报告；方向排名改为可选输入，只校验实际提供的排名与报告属于同一企业和批次。
4. 保留原有同行增强模式：选择样本组后，仍可生成 10 个可排名方向的排名，并将同行位置注入最终评级包。
5. 为单企业报告保存可空的 `cohort_id`，保证历史同行报告和排名数据继续可读取。
6. 前端增加“单企业分析/同行增强分析”选择；单企业分析不要求选择同行样本，同行增强分析才显示样本组和排名流程。
7. 评级等级仍由模型根据 11 个方向状态形成，Python 继续校验强弱约束、评级边界和证据引用；缺少同行排名不得直接降低评级。

## 验收标准

- 仅选择企业画像、行业背景画像即可生成单企业分方向报告；
- 完成 11 个单企业分方向报告后，不生成排名也能生成客户风险评级报告；
- 有同行样本时可以继续生成排名并显示同行位置；
- 旧的同行报告、排名和综合报告不受影响；
- 单企业报告中明确标注未进行同行比较，不虚构排名或比较结论。
