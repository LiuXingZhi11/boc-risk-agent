# 企业画像案例选择改造手册

## 需求

企业画像调查不再让业务人员手工填写案例 ID，改为从当前数据库已导入材料中选择案例。选项优先显示企业名称，同时保留案例 ID 作为区分；尚未导入材料时提示先进入材料管理。

## 实现步骤

1. 从材料表读取已有案例 ID 和材料标题，并与已保存企业画像的中文名称关联。
2. 在企业画像调查页用下拉框替换案例 ID 文本输入。
3. 选择项内部仍传递稳定的案例 ID，模型和数据库接口不改变。
4. 没有可选案例时不调用模型，提示先导入企业材料。

## 验收标准

- 页面不再显示案例 ID 文本输入框；
- 下拉选项能显示已导入企业的中文名称和案例 ID；
- 选择案例后仍可执行单领域或全选领域 ReAct；
- 不改变已有材料、画像和数据库记录。
