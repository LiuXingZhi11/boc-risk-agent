# 高级工具下线与清理手册

## 1. 目标

当前系统只保留四个业务工作区：材料管理、企业画像、行业背景、客户风险评级报告。下线历史案例、相似案例比较、核心风险判断和审批配置编辑等高级工具，并清理其专属提示词、脚本、服务和测试。

## 2. 清理边界

### 保留

- `v5_app.py` 的材料管理、企业画像、行业背景、客户风险评级报告四个页面；
- 企业结构化事实、主题分析、行业背景、11 个审批方向、同行排名和综合评级；
- 审批定义、指标计算、方向排名和综合评级的后台模块。它们是主流程的运行依赖，即使此前曾在“审批配置（高级）”页面中展示，也不能删除。

### 下线和删除

- 高级页面：历史案例、相似案例与报告、审批配置（高级）；
- 历史案例分析、画像比较卡、相似案例检索、详细比较和核心风险判断的前端服务；
- 不再有界面入口的旧金融风险案例审查模块及其脚本、专属提示词和测试。

## 3. 实施步骤

1. 第一阶段先从 `v5_app.py` 删除高级页面入口和路由，使当前系统只展示四个业务工作区。
2. 保留高级模块的底层代码、提示词和测试，作为未暴露的回退资产；本阶段不物理删除。
3. 待四个主工作区稳定验收后，再搜索高级服务函数的全部调用点，确认没有主流程引用。
4. 第二阶段才删除仅服务于高级模块的服务、提示词、脚本和测试；不删除仍被保留模块引用的通用代码。
5. 删除后搜索历史案例、比较卡、核心风险和金融风险案例关键词，确认没有主流程残留引用，并运行现行测试套件。

## 4. 验收标准

- 侧边栏只显示四个业务工作区；
- 四个业务工作区可正常导入、加载和生成其原有结果；
- `prompts/` 只包含当前四个工作区使用的中文提示词文件，不再保留旧功能兼容提示词；
- 没有主流程代码引用已删除的高级模块或提示词。
