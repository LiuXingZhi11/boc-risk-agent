## 2. 当前业务目标

系统从企业材料和行业报告中提取有证据的事实，形成企业画像、行业背景、风险评级指引分方向报告和客户风险评级报告；同行企业年报和样本内排名作为可选增强输入。

当前代码已经具备企业画像、行业背景、单企业风险评级方向报告、可选同行排名和客户风险评级能力。系统不再保留历史案例、相似企业和旧 Agent 功能。

当前主流程重点是：

1. 企业领域与行业基准的稳定关联；
2. 单企业分方向风险判断，不要求同行样本；
3. 同行企业标准化指标矩阵、样本内排名和排名赋分（可选）；
4. 风险评级指引审批点、方向总结和方向评价；
5. 汇总 11 个方向的客户风险评级报告。

## 3. 当前有效能力

- PDF、HTML 解析为 SourceAsset 和 EvidenceUnit；
- 企业与行业材料集合隔离；
- 企业十领域画像候选生成；

- 风险评级指引 11 个方向、单企业分方向报告、可选方向排名和客户风险评级报告；
- 单企业模式不绑定同行样本，报告明确标注未进行同行比较；同行增强模式保留原有样本和排名流程；
- 最近一次核心回归测试为 `235 passed`（排除 Streamlit 启动测试）；客户/供应商双侧分批规则、21 级评级边界和主题事实引用校验已纳入该结果。

## 6. 下一步先完成的业务设计

后续扩展或调整代码前，仍需先确认以下业务内容：

1. 企业十领域继续保留，还是合并成更少的审批方向；
2. 每个审批方向包含哪些固定审批点；
3. 每个审批点引用哪些行业维度；
4. 每个审批点使用哪些同行可比指标；
5. 哪些指标越高越好、越低越好、按阶段比较或只用于解释；
6. 同行样本选择规则和报告期；
7. 缺失值、并列名次、有效样本数和排名赋分规则；
8. 方向排名如何作为综合结论的补充，而不是评级的必需输入。

这些内容应先形成“审批方向—审批点—行业基准—同行指标—排名规则”总表。

## 8. 实施约束

- 每次代码变更前先在主技术手册写清需求、实现步骤和验收标准；
- 函数命名清楚，流程保持简单，不增加无业务必要的冗余检查；
- 模型不计算排名，Python 不补写企业事实；
- 未披露数据不等于零，不自动进入末位；
- 只表述样本内排名，不夸大为全行业排名；
- 表现得分与证据充分度分开；
- 画像、同行样本、排名和报告均保留人工审核门禁；
- 自动化测试不得调用真实付费模型。

## 9. 完成下一阶段的判定标准

- 至少一个审批方向能够关联企业事实、行业背景和同行指标；
- 同一批固定输入可重复得到相同排名；
- 报告显示原始值、有效样本数、名次和排名赋分；
- 缺失值不会被计算为零或最后一名；
- 每个审批点有企业现状、基准、排名、评价、证据和信息缺口；
- 方向总结不超出审批点；
- 结果保持 `pending`，人工批准后才进入综合报告。

## 10. 当前画像质量复核（2026-08-10）

### 复核要求

逐家将正式画像中的关键事实与对应 PDF 原文核对，优先检查：

1. 近三年收入、净利润、经营现金流和研发投入的年度、单位与口径；
2. 专利申请、授权、有效专利及其分项数量是否混淆；
3. 核心技术名称、技术来源、成熟阶段和技术储备是否完整；
4. 客户、供应商的角色、集中度、关联关系和交易期间是否错配；
5. 画像分析是否覆盖已提取事实，且明确披露范围和信息缺口。

### 实施步骤

1. 建立十家企业的 PDF 来源、EvidenceUnit、画像字段和主题分析清单；
2. 对确定性错误和缺失事实进行有证据引用的数据库修正，保留原始页码与摘录；
3. 对受影响主题重新执行分析，确保摘要、事实引用和信息边界同步更新；
4. 运行结构校验和测试，复核所有引用可回溯到当前 PDF，最后记录修正结果。

## 11. 企业报告期边界与画像提取规则

### 需求范围

以下两份非同期年报保留原始报告期，不与正式 2025 年同行样本混用：

- `哈工智能2021年报.pdf`：画像报告期按 PDF 实际披露年份记录为 2021 年；
- `赛为智能2024年报.pdf`：画像报告期按 PDF 实际披露年份记录为 2024 年。

两份年报均按当前企业画像的统一六个主题提取：基本信息与经营范围、治理与团队、财务与经营、产品与商业化、技术与知识产权、客户供应商与风险。事实必须引用本次 PDF 的 EvidenceUnit，未披露内容明确标记为信息缺口，不用模型臆测补齐。

企业发展阶段只有在原文明确使用“初创、成长、成熟、转型”等阶段性表述时才可作为结构化事实；不得由成立年限、上市年限或业务描述推断。专利、软件著作权、商标等知识产权类别必须分开记录：软件著作权数量不得写入专利申请或专利授权字段，专利数量必须保留发明、实用新型、外观设计、总量或新增量等原文统计范围。

### 实现步骤

1. 检查两份 PDF 文件和数据库中的来源记录，确定稳定的企业 case_id，避免重复导入；
2. 使用当前 3200 字符连续切片规则导入 PDF 和 EvidenceUnit，保留页码、标题和原文摘录；
3. 使用当前事实结构化流程提取原子事实，再按六个主题归并为企业画像；事实抽取使用 sampling，主题分析使用 DeepSeek thinking；
4. 对两家企业分别运行六个主题的画像分析，摘要必须基于已提取事实并保留证据引用、披露边界和信息缺口；
5. 只验收新增企业：核对企业名称、报告期、财务单位与年度、专利口径、核心技术完整性、客户供应商角色和所有证据引用；
6. 运行结构校验和自动化测试，确认已有企业画像、来源和行业背景数据未被修改。

### 验收标准

- 新增两个来源，已有来源数量和内容不变；
- 两家企业各有一份可追溯到本企业 PDF 的完整画像；
- 六个主题均有分析结果或明确的信息缺口，不能出现占位名称；
- 2021/2024 报告期、金额单位、专利申请/授权/有效口径不混淆；
- 画像事实、主题事实引用和来源 case_id 全部匹配；
- `pytest -q` 通过，新增流程不触发真实模型调用以外的测试副作用。
