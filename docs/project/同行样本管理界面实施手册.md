# 同行样本管理界面实施手册

## 需求

新增企业后，业务人员可以在系统内维护同行样本组，不再依赖脚本或直接修改数据库。样本组用于风险评级分方向报告、同方向排名和最终综合评级。

## 实现步骤

1. 在“客户风险评级报告 → 生成、审核与同行排名”工作区增加“同行样本管理”区域。
2. 仅允许高级业务人员创建和批准样本组；一般业务人员可以查看已批准样本，但不能修改样本口径。
3. 创建时选择已批准的行业背景画像，填写样本组 ID、名称、报告期、入样规则，并从已批准企业画像中多选企业。
4. 保存的新样本组先为待审核状态；高级业务人员批准后，才出现在风险评级和排名的可选列表中。
5. 企业选择保存企业的 `case_id`，不保存 `profile_id` 或中文名称；样本组至少包含两家企业。
6. 不覆盖已有样本组 ID；需要调整已批准样本时新建版本 ID，避免改变历史排名口径。

## 验收标准

- 可以把新增企业加入新的同行样本组并完成批准；
- 批准后的样本组能出现在分方向报告和排名的下拉选项中；
- 新增企业不在样本组时仍保持原有校验提示；
- 样本组保存的企业 ID 与正式企业画像的 `case_id` 一致。
