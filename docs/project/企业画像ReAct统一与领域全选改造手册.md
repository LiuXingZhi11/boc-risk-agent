# 企业画像 ReAct 统一与领域全选改造手册

## 需求

企业画像页面不再让用户选择固定流程或 ReAct 流程，页面统一使用当前企业 ReAct 调查。用户可以选择一个或多个有权限的调查领域；选择多个领域时按领域逐个执行 ReAct，并合并为一次待审核画像候选。

## 实现步骤

1. 删除企业画像页面的“调查模式”选择和固定流程分支。
2. 增加“选择全部可见领域”控件；全选范围只包含当前身份有权限的领域。
3. 新增多领域 ReAct 编排函数，逐个调用现有单领域 ReAct 服务，合并 `domains` 结果，保持原有候选审核格式。
4. 保留每个领域独立的证据搜索、读取上限和模型调用边界；多领域仅负责顺序编排，不合并不同领域的证据。
5. 保持审核入库、候选 JSON 下载和字段校验流程不变。

## 验收标准

- 页面不再显示调查模式选择；
- 可以一键选中当前身份可见的全部领域；
- 选择多个领域后，候选审核页显示对应的多个领域；
- 单领域和多领域结果都能继续批准写入正式企业画像；
- 现有测试全部通过。
