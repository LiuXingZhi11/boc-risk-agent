# 项目目录说明

本项目只保留当前可运行流程、当前业务规则、当前测试样例和当前材料。历史试验脚本、旧案例数据、旧评估产物和临时运行日志不纳入项目。

```text
README.md / v5_app.py / requirements.txt
src/                       核心实现
src/ui/                    页面服务按工作区拆分，v5_services.py 仅保留兼容入口
scripts/                   当前初始化、材料导入、画像审核和 Skill 工具
tests/                     自动化测试
prompts/data/              企业画像和行业背景数据规则
prompts/logic/             画像、审批、排名和综合评级规则
prompts/action/            行动建议规则
config/                    MCP、Skill 和本地模型配置
authorization/             权限配置
skills/                    具体 Skill 定义（skill.yaml、SKILL.md）
materials/                 企业、行业和参考材料
data/current_project.db    当前工作数据库
eval_data/                 当前画像审核测试样例
docs/                      当前项目、业务和技术手册
```

## 当前应阅读的文档

1. `README.md`：快速了解项目和启动方式；
2. `docs/project/PROJECT_HANDOFF.md`：当前代码、数据流和待办事项；
3. `docs/project/科技型企业风险辅助审查系统_当前与目标技术手册.md`：系统架构和验收边界；
4. `docs/project/本体设计与维护手册.md`：字段、关系和本体维护方式；
5. `docs/business/客户风险评级报告生成工作手册.md`：业务流程和报告输出；
6. `boc-risk-agent_MCP_Skill_Extension_Platform_Manual.md`：MCP/Skill 平台扩展规则。
7. `docs/project/目录分层与职责重构实施手册.md`：目录职责和后续分阶段整理方案。

`skills/` 是可维护的 Skill 定义目录；`src/platform/skills/` 和 `src/platform/mcp/` 是不可由业务人员直接维护的 Python 运行代码。

## 清理边界

- `data/current_project.db`、`data/uploads/` 和 `materials/` 属于当前运行材料，不要随意删除；
- `config/model_config.yaml` 保存本地模型密钥，已加入 `.gitignore`，不能提交；
- `__pycache__`、`.pytest_cache` 和临时日志可随时删除；
- 所有新增业务规则先更新当前手册，再修改代码。
