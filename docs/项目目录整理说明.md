# 项目目录整理说明

## 目标

将运行入口、源代码、原始材料、业务手册、审查留档和数据库分开存放，避免根目录同时堆放 PDF、图片、脚本和验收结果。

## 目标结构

```text
README.md / v5_app.py / requirements.txt / .env
src/                 核心实现
scripts/             可执行脚本，暂不移动以保持既有命令和测试兼容
tests/               自动化测试
prompts/             当前提示词与兼容协议
prompts/data/        企业画像本体、字段语义与数据层模型协议
materials/
  industry/          行业研究报告 PDF
  enterprises/       企业年报与招股说明书 PDF
  reference/         授信指引图片等参考材料
docs/
  project/           项目说明、交接与技术手册
  business/          授信审批指引与工作手册
  audits/            审查、校准与复核手册
data/
  current_project.db 当前工作数据库
  reports/           最终报告与核对表
  audits/            PDF 复核台账与审查结果
  logs/              历史运行日志
```

## 实施规则

1. 移动 15 份当前已入库的 PDF 后，同步更新 `data/current_project.db` 的 `sources.path`；不重新切片、不改变 source_id、EvidenceUnit 或企业画像。
2. 只移动已确认不被代码硬编码引用的根目录手册、图片和材料；`README.md`、`v5_app.py`、`app.py`、`requirements.txt`、`.env` 保留根目录。
3. 根目录文档移动后，更新 README、交接文档和审查台账中的链接。
4. 运行日志归档到 `data/logs`；`__pycache__` 和 `.pytest_cache` 属于可再生缓存，可删除。
5. 不移动 `src/`、`scripts/`、`tests/`、`prompts/`、`models/`、`eval_data/`、`sample_data/`；本体运行时文件统一位于 `prompts/data/`，设计手册位于 `docs/project/`。

## 验收

- 数据库 15 个来源路径全部可访问；
- 根目录不再保留原始企业/行业 PDF、授信图片或项目手册；
- README 的关键链接可定位到新目录；
- 运行最终报告与行业相关测试，确认材料路径和当前模板读取正常。
