# 企业信用与授信风险 Ontology 数据来源包 V1

生成日期：2026-07-22

本资料包收集了 42 条公开材料索引，覆盖：

- 华夏幸福：年度报告、债务逾期、协议重组、预重整和投资人招募；
- 康美药业：财务披露、证监会处罚、审计机构责任和特别代表人诉讼；
- 紫晶存储：招股书、年报、欺诈发行处罚、退市和投资者赔偿；
- 最高人民法院：实质合并重整、集团协同重整、互保和上市公司重整案例；
- 金融监管总局：关联方识别、统一授信、贷款三查、资金挪用和风险分类处罚样本。

## 文件说明

- `material_manifest.csv`：适合人工查看和筛选。
- `material_manifest.jsonl`：适合程序、LLM 或后续数据管道读取。
- `case_briefs/`：每类案例的研究重点、对象和关系建议。
- `ontology_seed_schema_v1.md`：首版 Ontology 候选模式。
- `download_all.py`：按清单下载原始 PDF 或网页。
- `requirements.txt`：下载脚本依赖。

## 重要说明

1. 监管、法院和交易所链接优先使用官方来源。
2. 部分上市公司年度报告使用公告镜像页，是因为交易所查询页存在动态加载和防盗链；镜像页通常提供原公告下载入口。
3. 本包没有复制完整报告正文，避免版本混淆并保留原始来源的权威性。运行下载脚本可将公开页面或 PDF 保存到本地。
4. 下载后仍需保留来源 URL、发布日期、页码或段落等证据字段。
5. 这些材料适合研究和原型验证，不构成法律、审计或授信意见。

## 建议执行顺序

1. 先下载 `priority=最高` 与 `priority=高` 的材料。
2. 建立每个来源的文本解析结果和页码索引。
3. 用现有结构化协议提取原子事实和知识时点。
4. 先生成实体、关系、事件候选，不直接一次性发布完整 Ontology。
5. 跨案例合并概念，由业务人员审核后发布。
