# 同行分方向排名

> 审阅镜像。模型输入为同一审批方向下全部企业的精简比较卡，不是原始 PDF。

```text
你负责对同一同行样本内企业的同一授信审批方向进行相对比较。
只能使用输入的精简比较卡和固定比较标准，不得补充外部事实。
不要输出分数，不要重新计算数值指标。
只有材料严重缺失、统计范围冲突或无法建立同口径判断时，才放入 not_comparable_case_ids。
没有数值指标本身不是不可比理由；相同审批点下有企业事实或已批准判断时，应进行定性比较。
若只能判断为相近，可放入同一并列排名组，并说明信息边界。
输出必须是合法 JSON，不得包含 Markdown。

输出 ranking_groups 和 not_comparable_case_ids。
ranking_groups 的每项包含 rank、case_ids、comparison_reason。rank 从 1 开始，表现相同的企业放在同一组；只对可比较企业排序。
除非确实存在材料严重缺失或口径冲突，不要把全部企业列入不可比较。
comparison_reason 使用简短中文，必须基于输入材料。
```

## 当前排名范围与边界

- 对上述 11 个审批方向分别排名；其中“量化评估工具应用”按定义不排名；
- 输入是一个方向下所有企业的精简比较卡：该企业的审批点判断、可比指标、风险、缓释因素、信息边界和引用；
- 比较标准来自 [07_审批方向报告.md](07_审批方向报告.md) 中相应方向的固定重点；
- 排名只表示当前样本内的相对位置，不是信用分数、授信评分或全行业排名；
- 企业间存在实质口径冲突或材料严重不足才可标记为不可比；“没有某个数值指标”本身不足以判为不可比。

## 排名逻辑（当前实现）

1. Python 为同一个方向的每家企业压缩一张比较卡，卡中只保留该方向的审批点观察、判断、可比指标、主要风险/缓释因素、信息边界和来源；
2. 模型先按该方向的固定比较重点逐张阅读卡片；
3. 先排除确有严重材料缺失或统计口径冲突、无法建立同口径判断的企业；其余企业必须比较；
4. 对可比企业做相对分组：同等表现可并列；模型要为每组写简短的比较依据；
5. Python 校验每家企业只出现一次、排名从 1 递增、可比企业至少两家，并将名次换算为仅供展示的样本内 `rank_points`；
6. 该 `rank_points` 不能跨方向相加，也不能替代综合 A-D 判断。

当前排序没有为每个方向配置统一量化权重或公式；固定比较重点和完整比较卡是约束，最终的组间相对判断由模型完成。这同样是当前可继续细化的业务规则缺口。

## 同行排名业务规则

1. 先确认同行样本属于可比较行业范围，且关键财务指标处于同一报告期、单位和合并范围；跨期材料只能用于试验或单企描述，不得混入正式数值排名。
2. 排名必须在同一审批方向内完成，不得用技术方向优势弥补财务方向短板，也不得把不同方向名次相加后重新排序。
3. 定量指标应先按可比口径比较；定性事项应依据同一方向的审批点观察、风险、缓释因素和信息边界比较。
4. 明确的重大风险事项应降低该企业在相关方向的相对判断，但不应自动影响无关方向。
5. 信息缺口只限制结论可靠性；除非已无法建立同口径判断，不得仅因缺少一个字段将企业排到末位或列为不可比。
6. 同等证据强度、表现相近的企业可并列；不得为了形成连续名次而人为拉开差距。
7. 排名理由必须同时说明领先或落后的具体依据以及必要的信息边界，不能只写“综合较好/较弱”。
8. 排名结果只能用于当前同行样本和当前报告期；新增企业、替换企业或补充同期材料后，必须对该方向全样本重新排名。
