# 提示词总目录

本目录用于集中审阅模型指令。**当前口径版本：2026-08-14。** 当前系统的提示词有两种形态：

1. **协议文件**：运行时由代码直接读取；修改后会影响对应功能。
2. **代码模板**：提示词需要拼入当前企业、证据、字段白名单或比较卡，因此仍由 Python 组装。本目录已为主流程提供审阅镜像；除第 9 步已直接读取模板外，其余镜像暂不改变运行行为。

后续如需统一改造，应将“代码模板”迁移为本目录的模板文件，再由代码注入运行时数据。迁移前，请以“当前代码位置”为实际生效来源。

每份主流程提示词文件均已自包含其对应的固定领域、字段范围、审批方向或评级规则，以及“输入—审查步骤—输出—边界”。审阅时不需要再依赖单独的总表。

## 本次统一更新的最终报告口径

- 11 个审批方向的最终状态只使用 `passed`、`conditional_passed`、`failed`、`insufficient_information`。
- `passed` 适用于已有充分事实、无明确不利事项的方向；常规监测、缺少同行指标或非关键明细，不应自动降为 `conditional_passed`。
- `conditional_passed` 只保留给有实质跟踪事项的方向，例如转化兑现、融资协议/特殊权利、整改履行或经营波动。
- `quantitative_assessment` 仅是试验性方法检查，不是企业风险不通过项，也不参与 A-D 评级。
- 最终报告的推进建议由 Python 根据 11 条方向状态计算，不由模型自由决定：A 为“可推进”，B 为“审慎推进”，C 为“有条件推进”，D 为“不建议推进”。

上述规则在 [07_审批方向报告.md](07_审批方向报告.md) 的判断移交要求和 [09_企业综合评级.md](09_企业综合评级.md) 的最终状态、评级与推进建议规则中完整说明。

## 其他非主流程的代码内提示词

这些功能不参与“企业画像 → 11 个审批方向 → 排名 → A-D 评级”，但当前代码仍可调用：

- `src/review/questions.py`、`src/review/comparison.py`：旧版风险案例辅助审查；

它们均已列入后续迁移范围，但不应和当前企业评级主流程的提示词混在一起审阅。
