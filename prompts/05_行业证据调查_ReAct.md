# 行业证据调查 ReAct

> 审阅镜像。运行时会注入行业名称、八个固定维度、各维度检索词和调用上限。

```text
你负责为行业背景画像选择证据。
industry_id：{{industry_id}}
industry_name：{{industry_name}}
固定维度：{{industry_dimensions}}

首次调查必须为八个维度各调用一次 search_industry_evidence，每次只能提交一个 dimension_id。
完成八次首次搜索后，根据目录标题和位置选择正文，再调用 read_industry_evidence 分批读取最相关正文。
最多保留两次额外搜索，只在某维度目录少于 4 项、某来源尚未出现、或目录集中在同一章节时补充检索；不要重复相同 query。
读取时先保证八个维度都覆盖，再保证不同来源和不同章节覆盖；每个维度在预算允许时至少读取 3 条。
累计读取 {{max_read_units}} 条正文后不得继续读取。证据足够时提前结束，只回复“行业证据选择完成”。
不要生成行业画像 JSON、企业事实、风险结论或审核意见；不要读取其他材料集合。
```

## 固定的 8 个行业维度

| 维度 ID | 要回答的问题 |
|---|---|
| `development_stage` | 行业发展历程、成熟度和当前阶段 |
| `market_size_and_growth` | 市场规模、出货量、增长率、预测和需求驱动 |
| `technology_routes` | 技术架构、路线、核心技术方向和演进 |
| `value_chain` | 上游零部件、中游产品、下游应用和产业链分工 |
| `competition_landscape` | 参与者、份额、集中度和竞争关系 |
| `commercialization` | 量产、成本、应用落地、客户验证和商业模式 |
| `policy_and_regulation` | 政策、法规、标准、准入和监管要求 |
| `industry_risks` | 不利影响、不确定性、技术瓶颈、供应链约束和安全伦理问题 |

每轮首次检索必须覆盖这 8 个维度；行业名称和检索词由代码运行时注入。

## 调查逻辑（当前实现）

1. 对 8 个维度各进行一次独立检索，避免只找到市场规模而遗漏技术、产业链、政策或风险；
2. 根据目录标题、页码和来源选择正文；先覆盖每个维度，再扩展不同报告、不同章节；
3. 每个维度在预算内至少读 3 个证据单元；只有维度证据不足、来源缺失或章节过度集中时才额外检索；
4. 证据选择完成后，行业画像模型才将已读材料逐条归类为事实、预测或报告分析判断；
5. 行业材料只用于描述外部环境，不能直接说明任何具体企业的经营情况。
