# 11 个审批方向报告

> 审阅镜像。审批方向、审批点、字段绑定和行业维度绑定不在提示词中定义，而在 `src/approval/guideline_definitions.py` 与 `src/approval/mappings.py` 定义后作为输入注入。

```text
你根据已审核的当前企业事实、行业背景和同行指标，撰写授信审批指引中的一个方向报告。
只能使用输入材料，不得补充外部事实，不得自行计算或改写指标名次。
行业背景只能解释外部环境，不能单独证明企业现状。
输出必须是合法 JSON，不得包含 Markdown。

输出顶层字段 one_sentence_summary 和 approval_points。
approval_points 必须与输入审批点一一对应，每项包含：
approval_point_id、enterprise_observation、industry_benchmark、peer_comparison、judgment、enterprise_item_ids、
industry_insight_ids、metric_ids、information_gap_numbers。
所有 ID 和编号只能从对应审批点输入中复制。
每个有明确企业判断的审批点至少引用一个 enterprise_item_id 或 metric_id；材料不足时在 judgment 中说明信息不足，不得编造事实。
```

### 最终状态移交口径

本步骤不直接输出 `passed`、`conditional_passed`、`failed` 或 `insufficient_information`；这些最终状态由下一步综合评级基于 11 个方向统一判断。但本步骤的 `judgment` 必须为该判断提供清晰、可复核的依据：

- 企业事实已经充分支持正面或中性判断、且没有明确不利事项时，直接写清“现有材料足以形成判断”，不要因为缺少同行指标、单项非关键明细或日常监测需要而套用“仍需关注”的保守模板。
- 只有存在与当前审批点直接相关的实质事项时，才写“需持续跟踪/待补充核实”，并说明具体事项、已披露的暂时接受依据和影响边界。
- 有直接不利事实时，必须写清事项、期间、当前状态和是否已有明确整改/解除证据；不能用一般优势或同行名次掩盖该事实。
- 信息缺口只在其确实阻碍当前审批点形成实质判断时引用；不要把输入中每一个未出现的字段都写成信息不足。
- 行业背景和同行名次只用于解释外部环境或相对位置，不能替代企业事实，也不能直接推出企业通过或不通过。

### 格式修复

```text
上一版输出未通过校验：{{validation_error}}。
请仅根据上方同一份输入重新输出完整合法 JSON；所有引用 ID 和信息缺口编号必须从对应审批点允许列表逐字复制，
不要增加任何新事实或解释。
```

## 当前固定的 11 个审批方向

| 审批方向 | 审批点 | 写报告时的固定比较/判断重点 |
|---|---|---|
| 行业市场空间 | 市场规模与增长空间；市场渗透与替代空间 | 市场规模和增长、产品阶段和市场认可度、替代或出海空间 |
| 行业竞争格局 | 进退壁垒与竞争位置；上下游产业链关系 | 进退壁垒、先发或后发优势、上下游关系和竞争稳定性 |
| 企业规范性 | 公司治理机制；财务与管理规范性 | 治理和内控、财务管理规范、法律和监管风险 |
| 技术实力 | 技术先进性；技术稳定性；技术转化为商业利益的可行性 | 技术先进性、稳定性、商业转化可行性 |
| 股权结构安排 | 控制权与股权稳定性 | 控制权稳定性、股东关系和后续变动风险 |
| 企业转型发展情况 | 企业转型与配套支撑 | 技术和产品积累、资金/供应链/客户等配套支撑 |
| 核心团队 | 核心创始人与团队 | 核心创始人和关键人员、团队背景与稳定性 |
| 股权融资影响 | 估值变化与融资节奏；投资机构与投资协议影响 | 估值和融资节奏、投资机构专业性、投资协议约束 |
| 财务情况 | 财务状况与偿债基础 | 经营规模、盈利和现金流、债务和持续经营基础 |
| 量化评估工具应用 | 样本内指标与排名适用性 | 指标口径、样本范围、排名适用性和局限；此方向不进行企业排名 |
| 反洗钱和制裁合规管理要求 | 反洗钱和制裁合规 | 客户和交易对手识别、监管与制裁暴露、已披露合规事项 |

每个审批点会由 Python 注入四类材料：对应企业事实、对应行业洞察、可比指标及样本内名次、信息缺口。字段绑定与行业维度绑定在 `src/approval/guideline_definitions.py`；行业只能作外部背景，不能证明企业自身事实。

## 审查逻辑（当前实现）

对每一个审批方向，再对其每一个审批点按相同顺序判断：

1. **企业现状**：先只依据该审批点绑定的企业结构化事实，说明已披露的现状、变化或事项；
2. **行业基准**：再引用绑定的行业洞察，说明该企业所处的外部环境；行业信息不得替代企业事实；
3. **同行对比**：如该审批点有已计算的指标及样本内名次，仅如实说明其位置和口径；不能自行重算；
4. **审批判断**：综合前三步，判断该审批点的支撑、短板、风险或无法判断之处；
5. **信息边界**：只有缺失会阻碍当前审批点形成实质判断时，才明确写“信息不足/待核实”；不得把缺失直接写成负面事实，也不得将非关键缺失机械写成待核实；
6. **引用**：每一个明确企业判断至少绑定一个企业事实或指标 ID；行业洞察、指标、信息缺口编号都只能从该审批点输入复制。

当前提示词没有为每个审批点配置“满足 X 即为好、低于 Y 即为差”的硬阈值。除财务等已计算指标的样本内名次外，方向判断主要由模型在固定证据范围内进行定性分析。这是当前可继续完善的业务规则缺口。

## 审批方向业务判断规则

### 行业市场空间

- 市场规模、增速和政策环境只说明外部机会；企业是否受益必须另有产品、商业化、收入、客户验证或交付事实支撑。
- 已商业化、试点、研发中的产品必须区分表述；产品多不等于市场渗透高。
- 未披露市场份额、订单或渗透率时，不得用行业预测替代企业市场地位。

### 行业竞争格局

- 竞争位置应结合技术、产品、客户/供应商结构和行业竞争资料判断；专利数、融资轮次或单一收入指标不能单独证明壁垒。
- 前五大客户或供应商集中度应结合期间变化、单一对手占比、关联关系和替代可能性解释。
- 年报以代称披露交易对手时，只形成客户识别和 KYC 的资料边界；不能直接认定交易异常、制裁风险或关联交易。

### 企业规范性

- 治理判断优先依据实控关系、内部控制、监管/司法认定和已披露整改事项；一般性风险提示不能等同于治理缺陷。
- 已发生行政处罚、纪律处分、保留意见、重大内控缺陷或明确未决事项，应如实说明事项、期间和当前状态。
- 没有治理或财务管理材料时，应写信息不足，不得自动判定规范或不规范。

### 技术实力

- 技术先进性应综合技术来源、具体技术内容、知识产权、团队背景、研发投入和同行可比资料；专利数量或研发费率只能提供局部支撑。
- 技术稳定性应优先看具体技术的成熟度、权属、量产/验证事实和关键人员稳定性；不得由“企业已有产品”推断全部核心技术成熟。
- 技术转化应同时有技术、产品商业化和经营结果中的至少两类直接证据；研发投入本身不等于转化成功。

### 股权结构安排、核心团队与股权融资影响

- 控制权稳定性应基于实控人、股东关系、表决权安排、质押、特殊协议或明确风险事项；缺少某项材料只形成核查边界。
- 团队判断只使用可核验的关键人员、教育与职业背景、任职和激励事实；不得将背景描述直接提升为管理能力评分。
- 融资影响应区分现金与债务事实、估值与协议事实、以及企业发展阶段；未披露融资协议不得推定存在不利条款。

### 企业转型发展情况

- 转型必须有主营业务、技术、产品、商业化或客户/收入变化的事实支撑；行业热门方向或企业宣传口号不足以证明已经转型成功。
- 配套支撑应分别看资金、供应链、客户验证和交付能力；任一项缺失时应指出边界，不能由其他项替代。

### 财务情况与量化评估工具应用

- 财务判断至少同时阅读收入、利润和经营现金流的连续期间变化；只看营收规模不能代表经营韧性。
- 现金余额、有息负债和持续经营事项用于判断偿债基础；缺少债务明细时只能说明偿债判断不完整。
- 归母净利润、扣非归母净利润和普通净利润必须按原始口径分别使用，不能混合比较。
- 量化指标只在报告期、单位、统计范围和样本范围可比时使用；样本内名次只能说明相对位置，不等同于信用评分。

### 反洗钱和制裁合规管理要求

- 该方向的重点是交易对手识别资料、交易规模/集中度、关联关系和已披露风险事项，而不是根据年报代称自动判断制裁风险。
- 只有取得真实法律主体、注册地、受益所有人等资料后，才能完成制裁名单、负面信息和受益所有人核查；当前材料不足时应写为待补充 KYC 资料。
- 已披露处罚、诉讼、违规或跨境限制应按原文事实说明；行业出口管制要求不能直接证明企业违反了规定。
