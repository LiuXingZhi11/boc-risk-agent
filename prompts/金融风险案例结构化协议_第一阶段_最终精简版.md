# 金融风险案例结构化协议（第一阶段｜最终精简版）

> 旧版 `app.py` 兼容入口专用，不参与当前企业画像、11 个审批方向、综合 A-D 评级或推进建议主流程。当前企业事实抽取以 `02_企业结构化事实抽取.md` 和 `科技型企业企业画像抽取协议_V1.md` 为准。

## 1. 任务目标

将输入案例整理为可追溯的结构化事实记录，作为下一阶段规则提炼的唯一输入。

本阶段只整理材料明确提供的信息，不解释风险机制，不提炼规则。

## 2. 必须完成

### 2.1 提取原子事实

每条事实只表达一个主要内容，并记录：

- `fact_id`：在全部案例中唯一，格式建议为 `CASE_ID_F001`；
- `statement`：对原文的忠实整理；
- `source_excerpt`：支持该事实的原文片段；
- `category`：事实类别；
- `assertion_type`：材料以何种方式陈述该内容；
- `event_time`：事实发生时间，无法确定时为 `null`；
- `knowledge_status`：相对于目标事件的实际获知时间；
- `uncertainty`：材料中未明确或无法确认之处。

`category` 只能取：

```text
context
entity_attribute
relationship
action
transaction
financial_observation
business_observation
review_action
risk_event
outcome
other
```

`assertion_type` 只能取：

```text
reported_fact
attributed_assessment
estimate_or_plan
uncertain_statement
```

`knowledge_status` 只能取：

```text
known_before_target
known_at_target
discovered_after_target
time_unknown
```

### 2.2 指定一个目标事实

每个案例必须从已提取的事实中选择一个 `target_fact_id`，作为本次分析关注的主要风险事件、风险状态或结果。

要求：

- `target_fact_id` 必须属于当前案例；
- 对应事实的 `knowledge_status` 必须为 `known_at_target`；
- 只能指定一个目标事实；
- 不得另行改写或合并多个事实作为目标事件。

### 2.3 记录不确定性

材料不足时使用 `null`、`time_unknown` 或 `uncertainty`，不得自行补齐。

## 3. 禁止事项

本阶段不得：

1. 提炼风险机制、规则、风险信号或审查建议；
2. 构建知识图谱、实体网络或关系网络；
3. 补充输入材料之外的知识、事实或解释；
4. 推断未明确给出的主体关系、交易路径、对应关系或行为目的；
5. 将相关、共现或时间先后改写为确定因果；
6. 提高关系、行为、结果、责任或确定性的语义强度；
7. 将归属观点改写为已确认事实；
8. 将计划、预测或估计改写为实际结果；
9. 使用材料未提供基准的相对评价；
10. 自行计算、推导或补充材料未直接给出的数值和时间；
11. 输出摘要、普适性判断、自我检查或质量评分。

## 4. 输出结构

只输出合法 JSON，不得输出 Markdown 代码块或额外说明。

```json
{
  "case_records": [
    {
      "case_id": "",
      "case_name": "",
      "source": null,
      "target_event": {
        "target_fact_id": "",
        "uncertainty": ""
      },
      "facts": [
        {
          "fact_id": "",
          "statement": "",
          "source_excerpt": "",
          "category": "other",
          "assertion_type": "reported_fact",
          "event_time": null,
          "knowledge_status": "time_unknown",
          "uncertainty": ""
        }
      ],
      "uncertainties": []
    }
  ],
  "uncertainties": []
}
```

## 5. 输出要求

1. `statement` 的含义不得超过 `source_excerpt`；
2. 同一事实不得重复登记，不同事实不得强行合并；
3. 目标事实必须存在且标记为 `known_at_target`；
4. 事实的获知时间只依据材料，不依据理论上的可发现性；
5. 不确定时保留不确定性，不得猜测。
