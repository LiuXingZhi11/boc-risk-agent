# 评估产物目录

本目录保存自动化或人工评估使用的输入、JSON 运行产物和报告样例，用于回归比较和问题复现。

这里的文件具有各自生成时的模型、Schema 和数据语境，不代表当前架构规范，也不作为项目实施步骤。当前设计、目标工作流和验收标准统一以根目录下的以下文档为准：

- `科技型企业风险辅助审查系统_当前与目标技术手册.md`
- `PROJECT_HANDOFF.md`
- `README.md`

新增评估产物时应保留：

- 输入材料或样本标识；
- 模型及生成参数元数据；
- EvidenceUnit 引用；
- 候选、拒绝记录和审核状态；
- 可重复执行所需的配置。

评估产物不得直接写入 `approved` 正式画像，也不得被引用为当前技术规范。
